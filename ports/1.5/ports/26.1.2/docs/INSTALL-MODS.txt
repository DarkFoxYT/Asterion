ASTERION 2.0.0 — MINECRAFT 26.1.2 POLISH BUILDS

Fabric is the default. Use Fabric Loader 0.19.5 with the supplied Fabric API and GeckoLib 5.5.2 JARs.
Amnetic is embedded; do not install another copy.

NeoForge: use NeoForge 26.1.2.109 and the supplied NeoForge GeckoLib 5.5.2 JAR.
Native Amnetic, its platform libraries, and Forgified Fabric API are embedded. Connector is not needed.

Java 25 is required. Use a separate test profile and world.
The Fabric artifact may also be used with a compatible Quilt loader; this revision was runtime-tested on Fabric and NeoForge.
