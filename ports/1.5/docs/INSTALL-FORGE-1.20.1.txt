ASTERION 1.5 - MINECRAFT FORGE 1.20.1

Use Minecraft Forge 47.1.3 or a compatible later release and Java 17.
Copy Asterion-1.5-forge-mc1.20.1.jar into your mods folder.
GeckoLib, native Forge Amnetic, Forgified Fabric API and their required runtime
libraries are embedded. Connector and separate library JARs are not required.
