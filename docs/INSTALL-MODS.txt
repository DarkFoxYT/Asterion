ASTERION PORT TEST BUILDS

Use a separate Minecraft profile and a new test world for each version.
Copy every JAR from ONE matching mods folder into that profile.

Fabric (default): Fabric Loader 0.19.5; bundled folder includes Fabric API and GeckoLib.
Quilt: Quilt Loader 0.30.1; use the same Fabric/Quilt mods folder, including Fabric API.
Amnetic is embedded in Asterion on Fabric/Quilt. Do not add a second copy.

NeoForge 1.21.1: NeoForge 21.1.248. Use all five supplied JARs: Asterion,
Amnetic, GeckoLib, Forgified Fabric API, and Sinytra Connector.
Use Java 17 for Minecraft 1.20.1 and Java 21 for Minecraft 1.21.1.

Veil is no longer required. Asterion forces its Amnetic TAA off.
External shader packs can have their own TAA settings; disable those in the pack.
The source worktree and validation report document remaining compatibility limits.
